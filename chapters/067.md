# Chapter 67

## Translation

*(untranslated)*

## Source

### Block 1

| 原文 | Pinyin | Literal |
| :--- | :--- | :--- |
| 天下皆謂我道大，似不肖。 | Tiān xià jiē wèi wǒ dào dà, sì bù xiào. | The whole world says my Tao is great, but seems unlike/unworthy (of comparison). |
| 夫唯大，故似不肖。 | Fú wéi dà, gù sì bù xiào. | Because it is great, therefore it seems unlike. |
| 若肖，久矣其細也夫！ | Ruò xiào, jiǔ yǐ qí xì yě fú\! | If it were like (others), for a long time it would have been small/insignificant\! |

### Block 2

| 原文 | Pinyin | Literal |
| :--- | :--- | :--- |
| 我有三寶，持而保之： | Wǒ yǒu sān bǎo, chí ér bǎo zhī: | I have three treasures, holding and guarding them: |
| 一曰慈，二曰儉，三曰不敢為天下先。 | Yī yuē cí, èr yuē jiǎn, sān yuē bù gǎn wéi tiān xià xiān. | The first is called compassion/deep love, the second is called frugality/conservation, the third is called not daring to function as the first/ahead of the world. |

### Block 3

| 原文 | Pinyin | Literal |
| :--- | :--- | :--- |
| 慈故能勇； | Cí gù néng yǒng; | Compassion, thus able to be brave; |
| 儉故能廣； | Jiǎn gù néng guǎng; | Frugality, thus able to be broad/expansive; |
| 不敢為天下先，故能成器長。 | Bù gǎn wéi tiān xià xiān, gù néng chéng qì zhǎng. | Not daring to be first in the world, thus able to compile/complete as the chief of tools/vessels. |

### Block 4

| 原文 | Pinyin | Literal |
| :--- | :--- | :--- |
| 今捨慈且勇，捨儉且廣，捨後且先，死矣！ | Jīn shě cí qiě yǒng, shě jiǎn qiě guǎng, shě hòu qiě xiān, sǐ yǐ\! | Now to abandon compassion and just be brave, to abandon frugality and just be expansive, to abandon the rear and just be first, is death\! |
| 夫慈，以戰則勝，以守則固。 | Fú cí, yǐ zhàn zé shèng, yǐ shǒu zé gù. | Now compassion, used in battle it wins, used in defense it is solid/firm. |
| 天將救之，以慈衛之。 | Tiān jiāng jiù zhī, yǐ cí wèi zhī. | Heaven will save/rescue them, using compassion to guard them. |
