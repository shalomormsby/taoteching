# Chapter 65

## Translation

…

…
this is mysterious integrity.

Mysterious integrity is deep and far-reaching…

## Source

### Block 1

| 原文 | Pinyin | Literal |
| :--- | :--- | :--- |
| 古之善為道者，非以明民，將以愚之。 | Gǔ zhī shàn wéi dào zhě, fēi yǐ míng mín, jiāng yǐ yú zhī. | The ancients who were masterful at executing the Tao, did not use it to enlighten the people, but to keep them unformatted/simple (yu). |
| 民之難治，以其智多。 | Mín zhī nán zhì, yǐ qí zhì duō. | The people are difficult to govern, because their cunning/cleverness (zhi) is excessive. |

### Block 2

| 原文 | Pinyin | Literal |
| :--- | :--- | :--- |
| 故以智治國，國之賊； | Gù yǐ zhì zhì guó, guó zhī zéi; | Therefore, using cunning/cleverness to govern the state is a thief to the state; |
| 不以智治國，國之福。 | Bù yǐ zhì zhì guó, guó zhī fú. | Not using cunning/cleverness to govern the state is a blessing to the state. |

### Block 3

| 原文 | Pinyin | Literal |
| :--- | :--- | :--- |
| 知此兩者亦稽式。 | Zhī cǐ liǎng zhě yì jī shì. | Knowing these two is also the absolute standard/pattern. |
| 常知稽式，是謂玄德。 | Cháng zhī jī shì, shì wèi xuán dé. | Always knowing the absolute standard/pattern, this is called Profound Virtue (Te). |
| 玄德深矣，遠矣，與物反矣，然後乃至大順。 | Xuán dé shēn yǐ, yuǎn yǐ, yǔ wù fǎn yǐ, rán hòu nǎi zhì dà shùn. | Profound Virtue is deep, is far-reaching, it reverts/returns with physical entities (wu), and only then reaches the Great Harmony/Smoothness. |
