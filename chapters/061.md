# Chapter 61

## Translation

*(untranslated)*

## Source

### Block 1

| 原文 | Pinyin | Literal |
| :--- | :--- | :--- |
| 大國者下流， | Dà guó zhě xià liú, | A large state is the lower stream, |
| 天下之交，天下之牝。 | tiān xià zhī jiāo, tiān xià zhī pìn. | The converging point of the world, the female/receptive of the world. |
| 牝常以靜勝牡，以靜為下。 | Pìn cháng yǐ jìng shèng mǔ, yǐ jìng wéi xià. | The female always overcomes the male through stillness, using stillness to position itself lower. |

### Block 2

| 原文 | Pinyin | Literal |
| :--- | :--- | :--- |
| 故大國以下小國，則取小國； | Gù dà guó yǐ xià xiǎo guó, zé qǔ xiǎo guó; | Therefore, if a large state lowers itself to a small state, it takes/wins the small state; |
| 小國以下大國，則取大國。 | Xiǎo guó yǐ xià dà guó, zé qǔ dà guó. | If a small state lowers itself to a large state, it is taken/won by the large state. |
| 故或下以取，或下而取。 | Gù huò xià yǐ qǔ, huò xià ér qǔ. | Therefore, one lowers itself to take, the other lowers itself and is taken. |

### Block 3

| 原文 | Pinyin | Literal |
| :--- | :--- | :--- |
| 大國不過欲兼畜人， | Dà guó bù guò yù jiān xù rén, | A large state merely desires to unite and nourish people, |
| 小國不過欲入事人。 | Xiǎo guó bù guò yù rù shì rén. | A small state merely desires to enter and serve people. |
| 夫兩者各得所欲，大者宜為下。 | Fú liǎng zhě gè dé suǒ yù, dà zhě yí wéi xià. | For both to get what they desire, the large must be the one to lower itself. |
